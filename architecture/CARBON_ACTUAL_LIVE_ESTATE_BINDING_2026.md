## 4. Economic execution boundary

The economic/value path is:

`intent → capability → authority/consent → governed plan → execution adapter → external acknowledgement → evidence → verification → state → value/Pulse → ledger/reconciliation`

Representation operations remain distinct:

`decimalization ≠ fractionalization ≠ tokenization ≠ minting`

Blockchain, distributed ledger, decentralization and specific settlement rails are implementation/transport choices around the governed operation; they do not themselves grant authority, establish ownership, or create constitutional value.

`Identity → Authority → Intent → Capability → Relationship → Event → Evidence → State → Value`
