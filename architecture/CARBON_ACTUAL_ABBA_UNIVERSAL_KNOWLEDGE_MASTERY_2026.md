# CARBON ACTUAL — ABBA UNIVERSAL KNOWLEDGE & MASTERY — 2026

ABBA treats knowledge as a structured, provenance-bound capability fabric rather than a flat memory store.

A knowledge object can be a word, a sense, grammar rule, quotation, code, riddle, joke, document, dataset, file, folder, repository, course, exam, procedure, standard, research result, theory, hypothesis, cultural object or media artifact.

Language capability is decomposed by language, script, modality and function. Dictionary vocabulary, senses, grammar, slang, idiom, quotations, literature and cultural context are capability-bearing objects.

Learning follows:

DISCOVER GAP → MAP DOMAIN → DISCOVER SOURCES → VERIFY PROVENANCE → ACQUIRE → LINK → PRACTICE → ASSESS → CAPTURE EVIDENCE → EXTERNAL VERIFICATION → UPDATE MASTERY → CHECK DECAY → REASSESS.

MASTER and EMERITUS states require external verification through the configured certification boundary. ABBA cannot certify itself.

Stale, superseded and contradictory knowledge is retained with lineage. Knowledge generated by ABBA is not automatically truth.

Mastery is competence state, never operational authority.
