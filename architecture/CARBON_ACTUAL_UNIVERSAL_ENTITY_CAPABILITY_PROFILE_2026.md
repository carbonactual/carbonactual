# Carbon Actual Universal Entity & Capability Profile — 2026

Status: CANONICAL COMMON-LAYER CONTRACT
Authority: HAPI World CANON.md + Carbon Actual operating-spine contracts.

## Rule
All recognized operational entities use one capability-bearing profile. Entity type determines context and legal/organizational semantics; it does not create a competing ontology.

## Entity classes
person, household, AI/entity, company/enterprise, government/public-authority, nonprofit/association/cooperative, institution/professional-body, product/service, asset/resource, place/territory, event/session, knowledge/media/document

## Shared profile dimensions
identity, representation, roles, relationships, rights, obligations, resources, capabilities, credentials, authority, delegation, schedule, location, communication, workflows, evidence, provenance, state, value, continuity, security, interfaces and adapters

## Capability semantics
Available capability is not permission. Role is not authority. A credential is not necessarily a license. A product route is not sovereignty.

## Full-capability law
Any entity may be composed with any relevant registered capability when its context, authority, eligibility, evidence, dependencies and policies allow it. The capability registry remains shared.

## Execution law
identity -> authority/Seal -> policy -> capability -> context -> evidence/readiness -> execution -> outcome -> audit

## Domain examples
- A person can participate in education, work, trade, investment, services, media, governance or other registered domains without being redefined as a new entity type.
- A company can own, offer, procure, employ, invest, trade, communicate, manage, operate or provide services through registered capabilities and lawful authority.
- A government can expose services, registries, decisions, procurement, revenue, infrastructure, inspections and public communication through the same common capability fabric with jurisdiction-specific authority.
- An AI entity can reason, communicate, search, build, monitor, coordinate or execute delegated work within its authority and scope; it does not inherit human authority merely by being minted.

## Non-duplication
Products project capabilities from this profile rather than creating human-only, company-only, government-only or AI-only universal capability stacks.
