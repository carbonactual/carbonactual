# Carbon Actual Universal Event & Interaction Fabric — 2026

Status: CANONICAL SHARED CAPABILITY
Authority: HAPI World CANON.md and Carbon Actual operating-spine contracts.

## Event forms
- in-person
- virtual
- remote/async
- media/broadcast-only
- hybrid
- externally hosted and observed
- recorded/reconstructed

## Session contract
Every session may declare: session_id, purpose, principal, participants, representatives, roles, capacities, invitation, agenda, channel, provider, location, schedule, attendance, floor, notes, minutes, materials, claims, findings, decisions, actions, evidence, media, provenance, protocol, realtime_state, visibility, retention and continuity.

## Capacity model
Capacity is session-scoped. A participant's role/capacity is bound to the session and time period in which it is exercised. Conflicting roles require explicit separation or policy resolution.

## Evidence model
source event != media artifact != transcript != summary != claim != verified finding != current state
External media may be ingested, indexed, observed or reconstructed without the system claiming to be the original host.

## Recognition and live updates
The fabric can represent attendance, speaker turns, floor state, protocol milestones, realtime updates, acknowledgements, claims, objections, decisions and action completion as event data.

## Universal event grammar
intent -> authority -> capability -> interaction -> event -> evidence -> verification -> state -> outcome

## Safety
Unknown observations remain UNKNOWN/POSSIBLE until supported by evidence. Recording, location, biometric, presence and public disclosure signals remain policy/consent governed.
