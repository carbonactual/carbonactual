# Carbon Actual Universal Composition Engine

**Status: CANONICAL COMPOSITION CONTRACT**

The composition engine assembles products, services, workflows, organizations, institutions, territories, agents and worlds from registered canonical primitives.

## Assembly model

```text
canonical objects
+ relationships
+ capabilities
+ resources
+ policies
+ workflows
+ interfaces
= governed composition
```

## Rules

1. Compose before creating a new primitive.
2. Reuse a canonical primitive before specializing it.
3. Specialization must declare its parent contract and cannot redefine inherited semantics.
4. Composition preserves identity, authority, provenance, lifecycle and auditability.
5. Components can be added, replaced, split or recombined through explicit versioned contracts.
6. Deprecated components remain available for migration/provenance where required.

## Product emergence

Existing products and future products can emerge from the same environment. They are not separate architectural universes; they are compositions of the shared substrate.

## Lego principle

Build the brick once. Register it. Make it discoverable. Compose it wherever needed. If multiple products independently recreate the same primitive, reconcile the duplicates back into the universal layer rather than multiplying foundations.
