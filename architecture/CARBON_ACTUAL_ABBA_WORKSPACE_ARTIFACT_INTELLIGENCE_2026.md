# CARBON ACTUAL — ABBA WORKSPACE & ARTIFACT INTELLIGENCE — 2026

ABBA treats the workspace as a lineage graph rather than a folder listing.

Files, folders, repositories, branches, commits, pull requests, releases, documents, datasets, assets and configurations carry identity, provenance, state and lineage.

The workspace engine detects:

- duplicates
- orphaned objects
- drift/divergence
- missing provenance
- unresolved lineage
- unsafe migration conditions

Migration is copy → link lineage → verify fingerprint → establish rollback → archive source when appropriate.

Deletion is not the autonomous default.

Recovery is capture current state → verify snapshot/lineage → build recovery point → recover/reconstruct → verify post-recovery state → reconcile provenance.

Workspace operations do not grant authority.
