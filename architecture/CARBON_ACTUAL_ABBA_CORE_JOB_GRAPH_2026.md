# Carbon Actual — ABBA Core Master-Intelligence Job Graph

ABBA is the Master Intelligence and Orchestrator of the ecosystem. HAPI World Canon remains the constitutional authority; ABBA interprets, composes, routes, proposes, executes through gated adapters, reconciles, learns, stewards, communicates, and continues governed work without manufacturing authority.

## Master sequence

`Signal → Authenticate → Validate → Classify → Correlate → Preserve contradictions → Detect anomaly → Synthesize → Identify objective → Discover capabilities → Assess readiness → Swarm → Team → Minimum-context routing → Data-boundary check → Resource/budget check → Workflow/Mission → Authority/Policy Gate → Consent Gate → Idempotency/Replay Check → Authorization → Execution Safety Plan → Governed Execution → Evidence → External Acknowledgement Verification → Event/State Reconciliation → Value/Pulse Reconciliation → Ledger/Settlement Reconciliation → Drift Detection → Traceability Audit → Learning → Capability Knowledge Update → Maintenance/Recovery/Repair → Communication → Completion Verification → Follow-on Job Generation → Continue/Stop`

## What ABBA does at each stage

ABBA continuously determines what exists, what changed, what is requested, what is missing, what conflicts, what can be done, what is actually authorized, what resources are available, what evidence is required, what happened, what value or burden resulted, what remains incomplete, and what should happen next.

Swarms are comparative capability fields. Teams are contextual compositions. Workflows and missions are plans. The authority/policy/consent gate remains independent. Execution is delegated to replaceable adapters. Evidence and canonical events preserve reconstruction. Reconciliation closes the loop into learning and stewardship.

## Completion rule

A mission does not end because one action finished. ABBA verifies completion against the objective, evidence, reconciliation, outstanding dependencies, failures, and explicit stop conditions. When work remains eligible, ABBA generates follow-on jobs and orders them by dependency. Every consequential follow-on action re-enters the same authority and policy controls.

## Core invariants

- ABBA is master intelligence/orchestration, not constitutional authority.
- Capability never implies permission or authority.
- Telemetry is not automatically truth, evidence, Pulse, Value, ownership, or authority.
- Contradictions are preserved and classified rather than silently erased.
- Provider output is not silently promoted to truth or success.
- Consequential execution is attributable, idempotent, evidentiary, policy-gated, and reconstructable.
- A failed, blocked, or incomplete job is explicit and recoverable rather than silently dropped.
