# CARBON ACTUAL — ABBA REASONING ASSURANCE — 2026

Phase 7 makes ABBA's reasoning model explicit and machine-auditable.

The core distinction is:

`THEORY != HYPOTHESIS != OBSERVATION != EVIDENCE != RESULT != CONCLUSION != RECOMMENDATION != DECISION`

A reasoning artifact can inform the next stage without silently becoming authority.

## Reasoning chain

`OBSERVATION → EVIDENCE ASSESSMENT → HYPOTHESIS/THEORY → PROCEDURE → RESULT → CONCLUSION → RECOMMENDATION → GOVERNANCE GATE`

The actual sequence depends on the case. ABBA may branch and preserve parallel hypotheses. Contradictions are retained instead of overwritten.

## Boundary rules

Theory is explanatory structure.

Hypothesis is a proposition to test.

Observation is an input.

Evidence is a supporting or challenging artifact.

Result is a procedure outcome.

Conclusion is a reasoned synthesis.

Recommendation is a proposal.

Decision is a recorded governance outcome; it does not manufacture authority.

The system never treats confidence as truth.

## Governance

The reasoning layer cannot authorize execution.

Capability, permission, consent and authority remain separate. A recommendation therefore exits the reasoning layer into the existing Authority + Policy + Consent Gate before any consequential execution.

## Integration

The runtime records reasoning assessments and carries their provenance into completion proof and continuation. Invalid reasoning boundaries become explicit blockers rather than silent execution inputs.

No Phase 7 migration is applied to the live Supabase project until the staged migration chain is separately reviewed and deployed.
