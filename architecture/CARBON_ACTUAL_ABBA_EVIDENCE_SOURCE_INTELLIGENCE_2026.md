# CARBON ACTUAL — ABBA EVIDENCE & SOURCE INTELLIGENCE — 2026

ABBA's external-world knowledge path is now explicitly provenance-bound.

SOURCE → PROVENANCE → FRESHNESS → INDEPENDENCE → CORROBORATION → CONTRADICTION → EVIDENCE CHAIN → REALITY STATE → KNOWLEDGE UPDATE.

A source is not truth.

Multiple copies of one source are not independent corroboration.

Stale information remains reconstructable and is marked stale rather than silently overwritten.

External observations retain their source, capture time, reality state and evidence references. They do not become canonical truth merely because they were ingested successfully.

Evidence-chain confidence is an assessment attribute, not a truth assertion.

All external-world outputs remain subordinate to the reasoning, governance and execution boundaries already established in the ABBA core.
