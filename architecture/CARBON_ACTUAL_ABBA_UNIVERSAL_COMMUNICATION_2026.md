# CARBON ACTUAL — ABBA UNIVERSAL COMMUNICATION — 2026

Communication is a capability with its own evidence lifecycle.

DEFINE INTENT → RESOLVE RECIPIENT → RESOLVE RELATIONSHIP → CLASSIFY DATA → CHECK PRIVACY → SELECT LANGUAGE/MODALITY → PROPOSE CHANNEL → AUTHORITY/CONSENT → SEND → VERIFY PROVIDER RECEIPT → VERIFY RECIPIENT ACKNOWLEDGEMENT → RECONCILE OUTCOME.

Delivery is not acknowledgement.

Provider acknowledgement is not recipient acknowledgement.

A failed, bounced, expired or unacknowledged communication is not successful completion.

Channel selection is a routing proposal. Language and modality are capabilities. Privacy and authority remain separate controls.

Communication outcomes participate in ABBA completion proof and continuation, but do not automatically become truth.
